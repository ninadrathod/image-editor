The Local Studio

A local image editor with a calm workflow — pick a preset, upload a photo, generate the edit on your machine. Nothing is hosted as a live app.

Fork on GitHub

How it works

  1. 1

    Choose a preset

    Browse gallery previews and click the look you want applied.

  2. 2

    Upload & generate

    Drop in your photo, then generate — a local Python API runs the preset and returns a PNG.

  3. 3

    Download

    Preview the edited result and save it to your machine.

Ready to try?

Fork the repo, run ./scripts/setup.sh then ./scripts/run.sh — apply your first preset locally in under a minute.
